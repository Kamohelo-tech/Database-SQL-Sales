# Enterprise Relational Database Architecture & Query Optimization

## 📝 Description
This repository contains the blueprints, schemas, and optimized relational scripts for an enterprise data architecture. It demonstrates proficiency in schema design, normalization (1NF, 2NF, 3NF), and high-performance querying under load.

## 🚀 Structural Highlights
*   **Relational Integrity:** Implements rigorous Primary Key/Foreign Key constraints, cascade rules, and indexes.
*   **Advanced Querying:** Contains complex inner/outer joins, aggregation matrices, subqueries, and views built to generate deep business insights.
*   **Performance Tuning:** Utilizes strategic indexing to drastically reduce query execution times on heavy transactional data tables.

## 🛠️ Database Environments
*   **RDBMS:** Microsoft SQL Server / MySQL
*   **Tools Used:** SQL Server Management Studio (SSMS) / Data Definition Language (DDL) scripts
